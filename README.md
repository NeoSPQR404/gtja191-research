# gtja191-research-tushare-data

Reproduction of 国泰君安《数量化专题之九十三：基于短周期价量特征的多因子选股体系》
(the 191-alpha short-period price-volume system), on tushare data.

* **Reference**: `../gtja191-reference/` — the report PDF + MSCI *Barra CNE5S Model
  Descriptor* (descriptor weights).
* **Data**: read-only panel from `../gtja191-tushare-data/data/` (2017–2025), plus
  申万一级 (SW2021 L1) industry fetched into `data/raw/` here.
* **Scope / decisions**: see [`DATA_AUDIT.md`](DATA_AUDIT.md) §6. Briefly — scope
  §3.3 + §3.4; window 2017–2025 (**out-of-sample** vs the report's 2012.01–2017.04);
  universe full-A ex-ST; industry SW L1; consensus descriptors proxied by
  forecast/express; alpha30 (FF3) + alpha143 (SELF) skipped → **189/191 alphas**.

## Layout

```
config.py              paths, universe/test params, CNE5S descriptor weights
src/
  Alpha_Set.py         the 191 alpha formulas (reference; data-dict → np array)
  Factor_Calculator.py per-stock reference operator implementation
  panel_engine.py      vectorized (date×stock) operators; runs Alpha_Set on full
                       panels with cross-sectional or time-series RANK
  alphas.py            per-stock runner (used by the equivalence validator)
  data_loader.py       panel load, full-A/topN universe, SW L1 industry, benchmark
scripts/
  validate_engine.py   panel engine ≡ per-stock reference (gap-free stocks)
  run_alphas.py        compute the 189 alphas, cache the long signal table
data/raw/              SW2021 L1 classify + membership (fetched)
report/                tables / figures / cache (gitignored cache)
```

## Run

```bash
# validate the engine port (panel TS-mode vs per-stock reference)
python scripts/validate_engine.py

# quick health check on N stocks (cross-section RANK, no cache write)
python scripts/run_alphas.py --rank cross_section --smoke 300

# full-A signal cache (see memory note below)
python scripts/run_alphas.py --rank cross_section --universe full_a
```

## Status

* **§3.3 alpha engine — ported & validated.** The engine is a byte-faithful port of
  the validated implementation; `validate_engine.py` reproduces the reference
  baseline exactly (147/188 exact on gap-free stocks in TS mode; the remaining 41
  are `RANK^RANK`/`CORR(RANK)`/`REGBETA(SEQUENCE)` alphas whose *absolute* TS
  magnitudes differ but are re-ranked cross-sectionally in production CS mode).
  Smoke run (300 stocks, CS mode): 189 alphas, ~95% of them ~97% non-zero.
  Degenerate ones (alpha21/116/147 `REGBETA(SEQUENCE)`, alpha146/152) come out
  all-zero and are dropped by the §3.4.1 `MIN_OBS_FRAC` filter.

* **§3.4 BARRA CNE5S styles — built & validated** (`src/barra_cne5s.py`,
  `scripts/compute_barra.py`). 9 styles as descriptor composites; consensus
  EPIBS / EGIBS / EGIBS_s **proxied** by forecast/express (NaN-aware per-cell
  composite auto-renormalizes a style where a proxy is missing). On top-1000:
  proxy coverage EPIBS 90%, EGIBS/EGIBS_s 92%; all styles ≥ 85% covered; CNE5
  correlation structure correct (**Vol–Liq +0.77, Size–Liq −0.57**, Value–Lev
  +0.62). Production full-A cache is generated by the §3.4 streamed pipeline.

* **§3.4.1 single-factor test — DONE on full-A** (`src/single_factor_test.py`,
  `scripts/run_single_factor_test.py`, `scripts/make_report.py`). Streamed off the
  signal memmap; styles via batched BARRA. Headline (full-A, 5103 stocks, see
  `RESULTS.md`): **|IR| mean 2.25→1.78** (report 2.57→1.05) — magnitude reproduced
  and monotonically declining with horizon (the report's core claim); but signed
  FR/IR ≈ 0 (slightly negative) — out-of-sample the alphas keep strong |IR| while
  ~half flip sign vs their 2010–2017 orientation. 170 valid factors, correlation
  pruning 170→66. Tables 7/8 + Figs 9-20 in `report/`.

### Memory note (16 GB machine)

Full-A (5103 stocks × 2183 days × 189 alphas) is ~8.4 GB as a float32 signal
matrix. Solved by: (1) alphas streamed to a disk **memmap** (`run_alphas.py
--memmap`), (2) BARRA descriptors computed in **stock batches** (`compute_barra.py`,
batch_size 600) — a single-shot full-A frame swap-thrashed a 16 GB machine to a
halt, batching keeps peak RAM ~2–3 GB, (3) the test **streams per-date slices**
off the memmap. Run the three as separate processes so each frees RAM. The alpha
stage is the long pole (~4.4 h, cached and reused); BARRA + test ~30 min.
